# Triangle Angle Lab

三角形の角度を、図形を動かしながら学べるブラウザ教材です。

HTML・CSS・JavaScriptだけで動作し、外部ライブラリや外部APIは使用していません。
1つの `index.html` だけで動作するため、GitHub Pagesなどの静的ホスティングでそのまま公開できます。

## 特徴

### 自由研究モード

- 三角形の頂点 A・B・C をドラッグして形を変更
- 各内角をリアルタイムで自動計算
- 三角形の内角の合計が常に180°になることを確認
- 底辺を水平に保つ機能
- 角度表示のON / OFF
- 初期状態へ戻す機能
- 自由研究のまとめ例を表示

### 問題モード

- 内角と外角から `x` を求める問題
- 「新しい問題」で問題を自動生成
- 答え入力と答え合わせ
- 答えの表示
- 解き方を段階的に確認

## 使い方

1. `index.html` をブラウザで開きます。
2. 「自由研究モード」では、青い頂点をドラッグして三角形の形を変えます。
3. 「問題モード」では、表示された角度から `x` を計算して入力します。

インストールやビルド作業は不要です。

## GitHub Pagesで公開する場合

このリポジトリをGitHub Pagesの公開元に設定すると、そのままWeb教材として公開できます。

公開元は `main` ブランチの `/(root)` を利用できます。

## 学習テーマ

- 三角形の内角の和
- 内角と外角の関係
- 角度の計算
- 図形を動かしながら行う観察・自由研究

## 対象

小学生高学年から中学生程度を想定していますが、図形の基本を確認したい人なら自由に利用できます。
